# FreeUni Object-Oriented Programming (OOP) Seminars

A collection of weekly seminar exercises, algorithmic implementations, unit tests, and software design patterns built in Java as part of the Object-Oriented Programming curriculum at the Free University of Tbilisi.

---

## 📁 Seminar Overview

### 1. `seminar1RomanNums` — Roman Numeral Converter
* Conversion logic between Arabic integers and Roman numerals.
* Includes JUnit tests verifying edge cases and numerical bounds.

### 2. `seminar2MathMystack` — Custom Stack & Math Utilities
* Custom Stack data structure implementation (`MyStack`) handling basic stack operations (`push`, `pop`, `peek`).
* Mathematical helper methods and corresponding unit tests.

### 3. `seminar3FizzBuzzPair` — Pair Data Structure & FizzBuzz
* Implementation of a generic/custom `Pair` data structure.
* Algorithmic solution for the classic `FizzBuzz` problem backed by automated unit tests.

### 4. `seminar4RelationOfClasses` — Object Relationships & Class Design
* Modeling class relationships (aggregation, composition, and inheritance).
* Practical design of interconnected OOP domain entities.

### 5. `seminar5Fraction` — Rational Number Arithmetic
* Custom `RationalNumber` / `Fraction` class managing fraction operations (addition, subtraction, multiplication, division).
* Encapsulates numerator/denominator reduction logic using Greatest Common Divisor (GCD).

### 6. `seminar6Filter` — Design Patterns: Interface Filtering
* Interface-driven architecture using a custom `Filter` interface.
* Multiple concrete implementation classes demonstrating dynamic filtering logic with unit testing.

### 7. `seminar7TreeButton` — Expression Trees & Event Handling
* Expression Tree data structure implementation built across three architectural approaches.
* Interactive GUI button clicker implementation exploring event-driven design.

### 8. `seminar8CalculatorMVC` — Model-View-Controller (MVC) Calculator
* Fully custom Desktop Calculator app written from scratch using the **Model-View-Controller (MVC)** design pattern.
* Complete separation of UI presentation, event listeners, and underlying mathematical evaluation logic.

---

## 🛠️ Concepts & Technologies
* **Language:** Java
* **Testing:** JUnit
* **Architecture & Patterns:** Model-View-Controller (MVC), Interface Segregation, Encapsulation, Generics, Expression Trees
* **GUI Development:** Java Swing / Event Handling
